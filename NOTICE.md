# Brutalist — licenses and attribution

Brutalist is an independent colorful theme for 2FA Theme API 2 / SDK API 1.
Its visual design uses square service cards, vivid colors, heavy outlines
and offset hard shadows. It has no affiliation with a third-party brand.

The account, command, navigation, internationalization and lifecycle adapter
is adapted from **Neubrutalism / 2fa-theme-neubrutalism**, itself adapted from
**Receipt / 2fa-theme-receipt** and **Pixel / 2fa-theme-pixel**, copyright
(c) 2026 2FA Pixel contributors, under the MIT License. The original license
is preserved in `licenses/Pixel-adapter-MIT.txt` and the root `LICENSE`.

This theme provides its own colors, typography and component treatment.
Typography uses locally installed system fonts; no third-party font files,
images or CDN resources are bundled or fetched. Account and OTP operations
are supplied by the 2FA host SDK.

The release archive includes this notice and applicable MIT notices in
`licenses/`. Development packages and the synthetic preview SDK are excluded.
